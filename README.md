# Unsent: The Micro-Confession Sprint

One micro-confession in exactly two parts: a `To:` line and the unsent line itself, written exactly as it was typed — no explanation after it. The number is still saved as "Home", and that is exactly why the message can never be sent: home now belongs to a stranger.

> To: my brother's old number, still saved as "Home"
>
> I typed happy birthday three times and deleted it every time — the number belongs to a stranger now.
